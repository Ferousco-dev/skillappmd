## §A — The environment-drift question, answered honestly

> *Can you rebuild the production environment from source, from scratch, with no human remembering
> a step? If not, what is the step that only lives in someone's head?*

**Local environment: yes.** `git clone`, check Node 22, one `npm ci` for the single package with
dependencies, run the suite. Nothing else. There is no build artefact that can disagree with source.

**Cloudflare: no — and nothing is deployed.** `wrangler.toml`, D1 and R2 bindings and an account do
not exist. That is `DEC-010`, decided at intake, not an oversight discovered here. The steps that
would live in someone's head are enumerated in `runbook.md` §5 **now**, while it costs nothing,
rather than at first deploy.

## §B — Criterion 1 found a real gap

`packages/connectors/gitskills/package-lock.json` — the lockfile for the project's **only**
dependencies — was untracked, caught by a `.gitignore` rule written for the front-end's root
lockfile.

**A build is not reproducible if the versions of its dependencies are local-only.** The ignore rule
is now anchored (`/package-lock.json`), ours is tracked, and 7 packages are pinned.

Also handled: new front-end artefacts (`components.json`, `public/`, `.claude/`) appeared in the
tree and were added to the ignore list rather than tracked. `CR-003` is the reason that reflex
exists — `git add -A` once swept 37 of another session's files into this repository.

## §C — What the rehearsal taught, which reasoning had not

**The foreign key refused the first corruption attempt.** Deleting `canonical_skills` rows failed
with `FOREIGN KEY constraint failed` while occurrences referenced them. Useful on a bad day: a
partial delete against canonical is **refused**, not silently applied, so corruption is more likely
to present as a failed operation than a quietly halved dataset.

**Index rebuild is mandatory after restore, not optional.** A restored database carries the
`search_index` rows its backup held. If the backup predates later records, search **silently
under-reports** rather than failing — the worst failure shape, because nothing looks wrong. Step 6
of §2.2 is now required. Rehearsing established this; reading the procedure would not have.
